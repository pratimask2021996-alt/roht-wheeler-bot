// Project Introduction

What We Have Built

Under this academic showcase, we have designed, programmed, and engineered an autonomous vehicle named "Obstacle Avoiding Bot.MIS" using the Arduino UNO microcontroller ecosystem.

Unlike basic remote-controlled toys or Bluetooth-driven cars, this robot is 100% autonomous. Once you switch it on, it requires no human intervention, pre-defined tracks, or smartphone applications to find its way. It possesses its own digital "brain" to process data and make instantaneous navigation decisions. The robot continuously scans the physical environment ahead of it, intelligently detects any barriers—such as walls, human footsteps, or random obstacles—and automatically alters its path to navigate safely without colliding.

// Our Vision

Why We Built This Project & Website

We set out to develop this robotics project and documentation website with three primary learning goals in mind:

01

Bridging Theory and Practical Execution

In our regular classes, we study programming languages, electronic physics, and algorithms purely on paper. Building this robot allowed us to experience firsthand how software lines of code can directly command and manipulate physical hardware devices.

02

Understanding Modern Automation

The modern industrial world is rapidly shifting toward smart autonomous systems—ranging from Tesla's self-driving cars to automated factory drones. Our project serves as a foundational prototype of that very same sensor-guided technology, helping us prepare for future engineering landscapes.

03

Creating an Open-Source Learning Hub

True knowledge expands when shared. We designed this comprehensive website so that our classmates and juniors can study robotics without feeling overwhelmed. By detailing our parts list, logic structure, and circuit schematics here, we hope to empower other students to build their own custom robots affordably.
